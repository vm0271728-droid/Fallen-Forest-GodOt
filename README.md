# Fallen Forest — Godot

Godot 4 + GDScript port of the Fallen Forest horror game.

## Canon

The master technical specification is stored in `docs/FALLEN_FOREST_MASTER_TZ.md`.

The Unity repository is used only as a reference. The Godot version is a native implementation.

## Stack

- Engine: Godot 4.7.1 stable
- Language: GDScript
- Renderer: Mobile
- Target: Android 11+ (API 30+), ARM64, landscape / 60 FPS

## Assets

Source assets are imported from the owner's Google Drive asset pack. Original files are preserved before optimization.
